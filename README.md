# Daisy Patisserie

İstanbul'da kafe, restoran ve işletmelere toptan tatlı satışı yapan Daisy Patisserie'nin tanıtım sitesi.

**Canlı site:** https://www.daisypatisserie.com

## Dosyalar

| Dosya | Açıklama |
|---|---|
| `index.html` | Ana site (tüm görseller ve veriler tek dosyada gömülü) |
| `admin.html` | Yönetim paneli — `www.daisypatisserie.com/admin.html` |
| `CNAME` | GitHub Pages özel alan adı kaydı |

## Yönetim paneli nasıl kullanılır?

1. Tarayıcıda `/admin.html` adresine gidin ve şifrenizle giriş yapın.
2. Yeni ürün ekleyin, popup ayarlayın veya şifre değiştirin.
3. **"Güncel Siteyi İndir"** butonuyla `index.html` dosyasını indirin.
4. Bu repoda **Add file → Upload files** ile indirdiğiniz `index.html` dosyasını yükleyin (mevcut dosyanın üzerine yazar).
5. 1-2 dakika içinde site güncellenir.

> Not: Admin panelinde yapılan değişiklikler yalnızca "Siteyi İndir + GitHub'a yükle" adımıyla kalıcı olur.
